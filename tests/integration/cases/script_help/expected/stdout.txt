Usage: twinline dedupe [OPTIONS] FILE [-o OUTPUT | --in-place]

Keeps the first line of every cluster of similar lines and removes the others.
Writes the result to standard output, to OUTPUT, or over FILE.

  -o, --output=FILE  Write the result to FILE (atomically)
  -i, --in-place     Replace FILE (atomically)
  -q, --quiet        Do not print the summary on standard error

Analysis options:
  --threshold=X    Near-duplicate threshold, above 0 and at most 1
  --strategy=NAME  jaccard, exact or minhash (also --exact, --minhash)
  --ngram=N        Longest word n-gram compared, 1 to 4
  -t, --threads=N  Worker threads, 1 to 256 or auto
  --exhaustive     jaccard: compare every pair (adds the mean similarity)
  --fold=MODE      Case folding: default or turkish
