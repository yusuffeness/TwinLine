TwinLine <version> - type 'help' for the list of commands.
twinline> Commands:
  open[!] FILE     Load FILE (use open! to discard unsaved changes)
  save [FILE]      Save atomically to FILE or to the current file
  new [FILE]       Open a new buffer, empty or with FILE
  buffers          List the open buffers
  switch N         Make buffer N the active one
  close[!]         Close the active buffer (close! discards changes)
  append TEXT      Add TEXT as a new last line
  insert N TEXT    Insert TEXT as line N
  delete N[-M]     Delete line N, or lines N to M
  replace N TEXT   Replace line N with TEXT
  edit N           Put line N in the input box to change it
  undo             Undo the last change
  redo             Redo the last undone change
  show[!] [N[-M]]  Print a page (from line N) or lines N-M; show! prints all
  goto N           Show line N in context; show continues from it
  find TEXT        List the lines containing TEXT (case-insensitive)
  analyze          Find near-duplicate lines in the background
  analyze-sync     Find near-duplicate lines and wait for the result
  cancel           Stop the running background analysis
  status           Show the file, unsaved changes and analysis progress
  threads          Show the progress of each analysis thread
  clusters [N]     Group similar lines, or show cluster N
  dedupe [N [K]]   Keep one line per cluster (or line K of cluster N)
  export FILE      Save the clusters as .json, .csv or .html
  set [NAME VALUE] Show or change the analysis settings
  help             Show this list
  quit[!]          Exit (quit! discards unsaved changes)
  exit[!]          Same as quit
